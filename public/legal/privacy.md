# Privacy Policy

This service (Quacky) is operated by Linus Kang. Data is processed on servers in Australia and/or Finland, and our content and services are available to users worldwide.

## 1. Information We Collect
### 1.1 Account Information

- Basic profile data (name, username, avatar)
- Email address from your authenticaion provider
- Account creation and edit timestamps

### 1.2 Authentication Data

- Login timestamps & provider used
- Last login IP address for security purposes

### 1.3 Content

Your profile:
- Bio, displayname, account settings, followers, following

Your generated content:
- Posts, replies, likes, reposts, quotes
- Direct messages
- Warm fuzzy messages
- Daily check-in information
- Quiz submissions

Communications:
- Feedback submissions
- Report abuse requests
- Support requests

### 1.4 Debug Data

- IP addresses for security monitoring
- User agent
- Session tokens
- Authentication timestamps
- API request information

## 2. How We Use Your Information

Quacky uses the collected information to:

- Fulfill contractual obligations (i.e. delivering site functionality, maintaining your generated content)
- Pursue security issues (i.e. preventing abuse by IP monitoring)
- Comply with legal requirements (i.e. retaining logs for security purposes)

## 3. Data Retention
### 3.1 Active Data
- User accounts: deleted upon request
- Posts, replies, direct-messages, warm fuzzies: retained indefinitely for content integrity, unless removed by the user

### 3.2 Debug logs & other information
- IP and Request logs: automatically deleted after 180 days
- Session tokens: after 30 days of inactivity
- Verification tokens: after 15 minutes, or if used by user

## 4. Data Sharing

**NO.** Quacky does not share data to anyone, or anywhere. All data is processed on servers under the control of Linus Kang and do not transmit anywhere else.

## 5. Your Rights
You have the right to:
- Request deletion of your personal data, which removes everything except for publicly available content (required for public integrity and interest. We retain this non-personal data under GDPR Article 17(3)(a) - freedom of expression/information.)
- Request data corrections
- Access and/or request an export of your collected data (contact privacy@linus.my)

Contact privacy@linus.my to exercise these rights.

## 6. Content Responsibility
- All created/edited content is automatically filtered
- Your UGC is subject to our automated moderation system
- We maintain all audit logs of user generated content
- Moderators actively monitor created content and reports for public interest

## 7. International Data Transfers

Data is stored in Australia with GDPR approved safeguards.
