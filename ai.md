# AI Declarations

AI was primarily used in debugging, like:

- when I had an error I didn't know how to fix, or when I needed help positioning UI (not a frontend dev, i like backend!)
- Debugging frontend code errors (i.e. Hydration Errors was most of it, UI Bugs, Things I didn't know how to do with ui)

No AI was used for generating full scripts like component pages, instead, I used AI to assist with only debugging. All backend code including APIs and the Quacky SDK was written by me without AI. Any application code (like in frontend) that was made by AI was extensively modified by me for authenticity, if not completely rewritten.

I also used AI to generate Unit & e2e tests for the backend, which you can find in /e2e and /tests. I did not modify these tests as they aren't used in the actual application, just helper scripts for me to test endpoints.

That basically sums it up!
