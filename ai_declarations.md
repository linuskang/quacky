# AI Declarations

AI has been used in the development of Quacky.

## Usage inside of this repository

These are the following uses that I've used AI in this codebase:

- Debugging code, for example the bug in v0.0.1 when posts didn't display properly on the homepage.
- Pentesting my application. For this, a combination of AI models from my Ollama server & Claude were used to pentest my application to ensure all API routes where properly authenticated.
- Autofill. An AGENTS.md and skills file have been included for AI models for autofilling repetetive scripts like API routes, when they all follow the same structure but different data queries. AI was not used here to generate fill scripts, but saves me time when doing repetitive tasks.
- Prototyping features: AI generated code has been removed after prototyping. The generated code was not used in this repository, but in a test server not released on GitHub. AI was used to prototype features & UI so I could have a wireframe to work off of when I'm lost on how to develop. All code in this reposititory is made by me otherwise.
