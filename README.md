### Introduction

Quacky is an all-in-one social media edutainment platform for teens. It is part of a broader development I'm programming over the next couple of months to actually pitch.

i dont really feel like yapping on this readme, but essentially:
- Quacky is a social media platform designed for schools to educate teens about responsible social media usage.
- Built like an realistic social media platform, with real users, all the features you would expect, and simplicity.
- Essentially, the experience is like **Banqur High**, where users unlock modules as they are educated with content generated by the app.
- Complete quizes to unlock more content, like posting, commenting, profiles, etc..
- Collect in game currency to unlock rewards that staff can decide (i.e. spotify premium yay)
- Staff can upload lessons, quizes, resources to the site as they wish to customise the experience.

so thats the gist of it, if you want to see the entire dev journey, check out the devlogs at https://quacky.space/devlog

## setting up local development environment

its extremely simple. you will need:

- a linux server with Docker running Postgresql
- node.js

get started by:

```bash
# cloning the repo
https://github.com/linuskang/quacky

# install dependencies
cd quacky
npm install

# env
cp .env.example .env

# apply migrations
npx prisma generate
npx prisma migrate dev

# start development server
npm run dev

# access at http://0.0.0.0:3000
```

## Self-hosting for production?

For my production deployment at https://quacky.space, i'm using 3 Raspberry Pi 5 nodes, each with:
- 8gb ram
- 128gb storage
- Running kubernetes in High Availability.
- each node runs the main Quacky app.

For the database, I'm using [managed prisma postgres](https://www.prisma.io/postgres). I'm self-hosting the qky cdn on a VPS.

The app is distributed to users using Cloudflare tunnels with Nginx Proxy Manager on my VPS as well, which forwards traffic to the pi cluster where it is load balanced.

Lucky for you, all you need to do is copy paste this compose file into your server!

```yml
services:
  app:
    image: ghcr.io/linuskang/quacky:latest
    restart: unless-stopped
    env_file: .env
    ports:
      - "3000:3000"
```

ensure that you've configured your ``.env`` file, and run the migrations using ``npx prisma migrate deploy``.

after, just run compose up when your finished:

```bash
docker compose up -d
```

Access the app at http://0.0.0.0:3000
