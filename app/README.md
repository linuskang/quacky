This is a standard nextjs application.

For the app layouts,
- ``(app)`` contains all pages that need an authenticated user.
- ``api`` is where all the backend routes are typed. Access them at ``/api/*``
- ``auth`` is all authentication endpoints like login, forgot password, signup, etc..
- ``docs`` is the API schema definitions, using Scalar
- ``home`` is just a homepage. wip.
- ``legal`` is privacy and terms
- ``openapi.json`` api schema
